# v0.5 都市品質比較

保存済みの異なる3都市(seed42/7/19)に新規出力専用の改善器を適用しました。before/afterのPNG比較、本文投影被覆率・形状/屋根/窓・地区指標を公開。seed42では改善後projectとSponge v2も同梱します。

`comparison.json` は全シードの成功/失敗と目標未達を保存。全件で実被覆率が増え、L字形状と屋根/窓の種類が増加。道路/登録空地と既存ID・敷地を維持します。`paper-verification.json` は実Paper/WorldEditでの全都市schematic読込と差分建築・Undo・復旧の結果です。

秘密設定とワールドは保存していません。実クライアント/Windows/Bedrockは未検証。再生成と制限は [QUALITY_V05.md](../../docs/QUALITY_V05.md) を参照してください。
